# 队友快速上手指南

> 适用环境：Windows 10 / 11。目标是本地启动三个服务：
> Flask 后端 `5000`、AI 助手 `5001`、Vue 前端 `8080`，浏览器访问 http://localhost:8080
>
> 本包**不包含** `venv`、`node_modules`、`.env`（这些必须每台机器自己生成）。

---

## 0. 需要先装好的软件

| 软件 | 版本 | 下载 |
|---|---|---|
| Python | **3.10.x**（推荐 3.10.11） | https://www.python.org/downloads/release/python-31011/ |
| Node.js | **18 LTS 或更高**（实测 24 可用） | https://nodejs.org/ |
| MySQL | **8.0+**（5.7 会因排序规则报错） | https://dev.mysql.com/downloads/installer/ |

安装时勾选 **Add Python to PATH**；MySQL 安装时记住 root 密码。

检查是否装好（PowerShell）：

```powershell
python --version     # 应显示 Python 3.10.x
node -v              # 应显示 v18.x 或更高
mysql --version      # 应显示 8.0.x
```

> 建议把项目解压到**纯英文路径**，例如 `D:\medicine`，少踩编码相关的坑。

## 1. 创建虚拟环境并安装 Python 依赖

在**项目根目录**（与 `app.py` 同级）打开 PowerShell：

```powershell
python -m venv venv
.\venv\Scripts\python.exe -m pip install --upgrade pip
.\venv\Scripts\python.exe -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

**如果卡在 `mysqlclient==2.2.0` 编译失败**（Windows 没装 MSVC 时的常见情况）：

```powershell
# 用记事本打开 requirements.txt，删掉下面这一行，然后重新执行上面的 pip install
mysqlclient==2.2.0
```

项目实际用的是 `PyMySQL`，删掉不影响运行。

---

## 2. 配置 `.env`

```powershell
copy .env.example .env
notepad .env
```

至少修改这两项：

```ini
DB_PASSWORD=你的MySQL root密码
DEEPSEEK_API_KEY=你的DeepSeek密钥     # 没有就留空，AI 助手会返回占位文案
```

其余保持默认即可（`127.0.0.1:3306` / `root` / `medicalinfo`）。

> `.env` 里有密码，**不要**提交到 git、也不要再发给别人。

---

## 3. 导入数据库（344 条示例病例）

确认 MySQL 服务已启动，然后在项目根目录执行：

```powershell
.\venv\Scripts\python.exe -m spiders.import_database
```

预期输出：

```
✓ cases表创建成功
✓ 表中共有 344 条记录
```

脚本会自动创建 `medicalinfo` 库和表，不需要手动建库。

## 4. 安装前端依赖

```powershell
cd front-end-template-1-master
npm install
cd ..
```

---

## 5. 模型权重（「在线预测」页需要）

两种方式，任选其一：

**方式 A：已有权重文件** —— 检查以下两个文件是否存在，存在就跳过本步：

```
machine\medical_model.pth
machine\bert-base-chinese\pytorch_model.bin
```

如果拿到的是单独的 `medicine-weights-v1.0.zip` 权重包，把它**解压到项目根目录**即可
（压缩包内已保留 `machine\...` 目录结构，会和项目里的其他文件合并）。

**方式 B：自行下载**（约 780 MB，需要联网）：

```powershell
.\venv\Scripts\python.exe download_weights.py
```

> 没有权重也能启动，大屏、数据管理、报告都能用，只有「在线预测」会提示模型未加载。

## 6. 启动

双击项目根目录的 **`start-all.bat`**，会弹出 3 个窗口：

| 窗口标题 | 服务 | 地址 |
|---|---|---|
| `Flask-5000` | 后端 API | http://localhost:5000 |
| `SocketIO-5001` | AI 助手 | http://localhost:5001 |
| `Vue-8080` | 前端 | **http://localhost:8080** |

耐心等待：

- 后端首次启动要加载模型，约 **1~2 分钟**，看到 `Running on http://127.0.0.1:5000`；
- 前端要编译，约 **1~2 分钟**，看到 `Compiled successfully` 和 `App running at: http://localhost:8080`。

然后浏览器打开 **http://localhost:8080**（白屏就按 `Ctrl+F5` 强刷）。

> **不要关闭这三个窗口**，关掉对应窗口就等于停止该服务。

停止服务：关闭三个窗口，或双击 `deploy\停止服务.bat`。

### 不想装 Node？可以用预构建版本

包里已经带了构建好的 `dist`。如果只想把系统跑起来看效果、不打算改前端代码，
可以跳过第 4 步（`npm install`），直接双击 **`deploy\一键部署测试.bat`**：

- 它等价于 `python deploy\deploy.py all`，会启动后端 5000 + 静态前端 8080（不依赖 Node），
- 并自动执行 14 条冒烟测试，生成 `docs\阶段四-测试报告.md`。

代价是前端页面是打包后的版本，改了 `src` 里的 Vue 代码需要重新 `npm run build` 才生效。

## 常见问题

| 现象 | 原因 / 解决 |
|---|---|
| `No Python at '...'` | 你用的是别人拷来的 `venv`。删掉 `venv` 文件夹，按第 1 步重建。 |
| `mysqlclient` 安装失败、缺 MSVC | 从 `requirements.txt` 删掉 `mysqlclient==2.2.0` 再装。 |
| `DB_PASSWORD is not set` / 数据库连接失败 | `.env` 没创建，或密码不对；确认 MySQL 已启动。 |
| MySQL 报 `utf8mb4_0900_ai_ci` 不支持 | MySQL 版本低于 8.0，升级到 8.0+。 |
| 前端窗口报 `ERR_OSSL_EVP_UNSUPPORTED` | 用 `start-all.bat` / `start-dev.bat` 启动（已内置 `NODE_OPTIONS`）；不要直接用 `npm run serve`。 |
| 8080 打不开 / 一直转圈 | 前端还在首次编译，等 1~2 分钟；或窗口里有报错，检查 `node_modules` 是否装完。 |
| 端口被占用 | 关掉旧的 `Flask-5000` / `SocketIO-5001` / `Vue-8080` 窗口后重试。 |
| 「在线预测」提示模型未加载 | 缺少 `machine\medical_model.pth`，见第 5 步。 |
| AI 助手只返回占位文案 | `.env` 里的 `DEEPSEEK_API_KEY` 没填或无效。 |

更完整的排错说明见 `docs\运行手册.md`。
